# Checklist Bot

Telegram-бот для управления чеклистами дизайн-проектов.

## Возможности

- Создание проекта в групповом чате (`/start_project`)
- Разделы внутри проекта: Мерч, Декор, Полиграфия и любые другие
- Задачи с дедлайном и статусом (В работе / На согласовании / На доработке / Готово)
- Управление задачей через inline-кнопки прямо в чате
- Борд арт-директора в личке с фильтрами по проекту и статусу

## Команды

| Команда | Где | Что делает |
|---|---|---|
| `/создать_чеклист` | Группа | Регистрирует проект в этом чате |
| `/показать_чеклист` | Группа | Показывает полный чеклист |
| `/добавить_раздел` | Группа | Добавляет раздел (Мерч, Декор...) |
| `/добавить_задачу` | Группа | Добавляет задачу |
| `/изменить_сроки_реализации` | Группа | Меняет даты проекта |
| `/редактировать_задачу_N` | Группа | Открывает карточку задачи №N |
| `/все_задачи` | Личка | Борд арт-директора со всеми проектами |

## Деплой на Railway (бесплатно, ~10 минут)

### 1. Создать бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумай имя и username
3. Скопируй токен — это твой `BOT_TOKEN`
4. Добавь бота в нужные групповые чаты и дай ему права администратора

### 2. Залить код на GitHub

1. Создай аккаунт на [github.com](https://github.com) если нет
2. Создай новый репозиторий (New repository)
3. Загрузи все файлы из этой папки в репозиторий

### 3. Задеплоить на Railway

1. Зайди на [railway.app](https://railway.app) → войди через GitHub
2. Нажми **New Project** → **Deploy from GitHub repo** → выбери свой репозиторий
3. Railway автоматически обнаружит `Procfile`

### 4. Добавить PostgreSQL

1. В проекте Railway нажми **+ New** → **Database** → **PostgreSQL**
2. После создания базы нажми на неё → вкладка **Variables**
3. Скопируй значение `DATABASE_URL`

### 5. Добавить переменные окружения

В Railway → твой сервис → вкладка **Variables** → добавь:

```
BOT_TOKEN=токен_от_BotFather
DATABASE_URL=скопированный_из_postgres
ART_DIRECTOR_IDS=твой_telegram_id (узнать можно у @userinfobot)
```

### 6. Готово

Бот запустится автоматически. Зайди в групповой чат, напиши `/создать_чеклист`.

## Структура файлов

```
checklist_bot/
├── bot.py              # точка входа
├── config.py           # переменные окружения
├── requirements.txt    # зависимости
├── Procfile            # для Railway
├── db/
│   ├── __init__.py     # инициализация пула БД
│   ├── models.py       # SQL схема таблиц
│   └── queries.py      # все запросы к БД
├── handlers/
│   ├── common.py       # форматирование, утилиты
│   ├── projects.py     # команды проекта
│   ├── tasks.py        # задачи и разделы
│   └── board.py        # борд арт-директора
└── keyboards/
    └── inline.py       # inline-клавиатуры
```

## Получить свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой числовой ID.
Вставь его в `ART_DIRECTOR_IDS` (если арт-директоров несколько — через запятую: `123,456`).
